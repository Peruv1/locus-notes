# Участие в разработке

1. Сделайте fork и создайте ветку для конкретного изменения.
2. Используйте Node.js 22.12+ и установите зависимости: `npm ci`.
3. Перед экспериментами в `npm run dev` задайте `LOCUS_DATA_DIR` на отдельную папку вне репозитория.
4. Выполните `npm run typecheck` и `npm test`. Для изменений редактора, хранения или Electron запустите соответствующие Electron-проверки последовательно.
5. В pull request объясните результат изменения, причину и проверки.

Сохраняйте совместимость заметок, Корзины, восстановления, вложений и старых метаданных. Избегайте несвязанных рефакторингов и обновлений зависимостей.

Не добавляйте реальные заметки, секреты, локальные пути, логи, установщики или профили Electron. Очищайте диагностику перед отправкой в issue. На скриншотах используйте искусственные заметки.

Порядок сборки и проверки: [RELEASE_CHECK.md](RELEASE_CHECK.md).
