# Состояние проекта

Locus Notes **1.3.0** — локальное приложение для Markdown/LaTeX-заметок на Windows x64. Интерфейс на русском.

## Релиз 1.3.0

Добавлены безопасное удаление разделов, подсказки LaTeX и язык заметки. Исправлены активация меню через Alt/Shift+Alt, прокрутка длинных заметок и горячие клавиши при русской раскладке.

Подготовка публикации добавляет документацию, лицензии и исключения локальных данных из Git. Точечное обслуживание безопасности обновляет встроенный Electron и санитайзер, запрещает уход с доверенной страницы и проверяет отправителей IPC. Новых пользовательских функций при подготовке публикации нет.

## Архитектура

- `src/main/index.ts`: окно, протокол вложений и IPC.
- `src/main/storage.ts`: Markdown/YAML, config, вложения, Корзина, атомарная запись и backups.
- `src/preload/index.ts`: ограниченный API через contextBridge.
- `src/renderer/app.ts`: состояние UI, textarea, autosave и Markdown/KaTeX preview.
- `src/shared/latex.ts`, `src/renderer/latex-autocomplete.ts`: подсказки.
- `src/renderer/styles.css`: viewport и прокрутка рабочей области.
- Версия приложения: `package.json`; схема конфигурации остаётся `1`.

Данные хранятся отдельно от исходников и установки. Чтение старых заметок не требует массовой миграции.

## Ограничения

Нет cloud sync, телеметрии, аккаунтов или автообновлений. Данные не зашифрованы. Отдельный экспорт PDF не заявлен. Фактическое переключение RU/EN требует ручной проверки. Очень большие заметки не виртуализированы. Удаление раздела использует backups и последовательные записи, а не транзакцию всей файловой системы. Windows-сборки не подписаны.
