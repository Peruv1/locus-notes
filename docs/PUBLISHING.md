# Публикация v1.3.0

Исходники, документация и артефакты подготовлены локально. Удалённый репозиторий, push, tag и GitHub Release при подготовке не создавались.

1. Создайте или проверьте нужный GitHub-репозиторий и выберите владельца и видимость.
2. Если нужно, инициализируйте Git. Проверьте состав первого коммита и создайте его со своей Git-идентичностью. Данные, профили, логи, output и установщики должны быть исключены.
3. Укажите настоящий remote и выполните push проверенной ветки.
4. Создайте и отправьте tag `v1.3.0` на проверенный release-коммит.
5. Создайте GitHub Release для этого tag и вставьте [готовый текст](releases/v1.3.0.md).
6. Прикрепите из `release/` новые проверенные `Locus-Notes-Setup-1.3.0-x64.exe` и `Locus-Notes-Portable-1.3.0-x64.exe`, а также [SHA-256](releases/v1.3.0-SHA256SUMS.txt).
7. Проверьте название, tag, файлы и текст, затем опубликуйте Release.

Перед распространением выполните оставшиеся ручные проверки из [RELEASE_CHECK.md](../RELEASE_CHECK.md).

Когда станет известен адрес репозитория, его можно отдельно добавить в metadata. Фиктивные URL и личности автора не использованы.

Готовые и исторические exe остаются на диске и исключены из Git. Локальные отчёты и снимки до изменений тоже исключены. Публикуйте только проверенные исходники и выбранные Release-артефакты.
