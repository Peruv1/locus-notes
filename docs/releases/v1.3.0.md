# Locus Notes 1.3.0

Релиз улучшает редактор, безопасное управление разделами и работу с локальными заметками.

## Добавлено

- Подсказки 33 распространённых команд LaTeX возле курсора с выбором клавиатурой и мышью.
- Язык заметки: Auto, русский и английский.
- Удаление разделов с подтверждением. Заметки остаются в «Без раздела», создаются восстановимые backups.

## Исправлено

- Alt и Shift+Alt больше не активируют скрытое системное меню Electron.
- Длинные заметки прокручиваются внутри редактора и preview; sidebar и элементы управления остаются на месте.
- Ctrl+N/F/K/S работают при русских значениях клавиш.

## Безопасность и подготовка публикации

- Встроенный Electron обновлён до 42.11.10 для устранения опубликованных уязвимостей.
- DOMPurify обновлён до 3.4.16; исправлена зависимость HTTP-кэша инструментов сборки.
- Запрещён уход с доверенной страницы; IPC принимает запросы только от основного доверенного frame.
- Подготовлены документация, MIT License и лицензии зависимостей.

## Скачать

- **Установщик:** `Locus-Notes-Setup-1.3.0-x64.exe`
- **Portable:** `Locus-Notes-Portable-1.3.0-x64.exe`

Windows x64. Интерфейс на русском. Portable запускается без установки и хранит данные в пользовательской папке Документы. Сборки не подписаны; возможно предупреждение SmartScreen. Сверяйте SHA-256 из приложенного файла контрольных сумм.

## Совместимость

Старые заметки без поля языка читаются как `auto` без массовой перезаписи. Корзина, восстановление, вложения, Хранилище и схема конфигурации сохранены.

Перед обновлением закройте приложение и скопируйте всю папку данных. Экспорт включает активные заметки, вложения и config, но не Корзину и историю backups.

## Проверки

- 25 автоматических тестов прошли.
- Существующие Electron end-to-end и UI regression checks прошли.
- UI релиза проверен на development и packaged production.
- Production-код, установщик и portable успешно собраны.
